How to set it up
  1. Unzip the download and open the folder in a terminal.
  2. Copy .env.example to .env and set API_WRAPPER_KEY.
  3. In docker-compose.yml, change the published port to 8002:8000, because this app already uses 8000.
  4. Add your detector's provider config (see the wrapper's README), then run docker compose up --build.
  5. Click + add source and enter http://localhost:8002.
  6. Choose it under Active Detector.
