# Downloads

`detector-api-wrapper-template.zip` goes here. It is what the chat page's
"Download API wrapper template" button serves (`GET /admin/wrapper-template`).

To make it: on GitHub, open the Detector API Wrapper repo, switch to the
`develop` branch, click Code > Download ZIP, and save the file here under the
name above. It holds the wrapper's Dockerfile, docker-compose.yml,
.env.example and source. Never put a real `.env` in it.

Until the file is here, the button shows "The API wrapper template isn't on
this server yet" instead of downloading anything.
